# 2026-11-21

## 排查：TTSDK 构建报 "Incompatible color space with graphics API"

- 报错实际来自工程 `C:\Unity\project\Unity2021_蛋糕排序_CakeSort3DColorPuzzle`（Unity 2021.3.45f2c1），不是 TapAway 工程。
- 根因：该项目 `ProjectSettings.asset` 的 `m_ActiveColorSpace: 1`（Linear），而 `Assets/Editor/StarkBuilderSetting.asset` 中 `isWebGL2: 0`，StarkBuilder 构建时把 WebGL 图形 API 设为 OpenGLES2（WebGL 1.0）。WebGL 1.0 无 sRGB framebuffer，不支持 Linear，Unity BuildWebGL 直接中止。
- 参照：同机可用的抖音小游戏工程 `Unity2022_PigeonPop疯狂鸽子`、`Unity2022_叠高楼DroppyTower` 均为 Gamma + WebGL1（08000000 / OpenGLES2）。
- 修复建议：优先把 Color Space 改 Gamma（2D 休闲游戏，RealToon 支持 Gamma 但材质颜色需微调）；或保留 Linear 但把 isWebGL2 改 1 并只启用 WebGL 2.0（抖音端兼容性风险较高）。
- 备注：Unity 运行时直接改 ProjectSettings.asset 会被覆盖，需在 Editor UI 改或先关闭 Unity。

## 修复：Google.IOSResolver.dll 报 "Unable to resolve reference 'UnityEditor.iOS.Extensions.Xcode'"

- 环境确认：编辑器 `C:\Unity\engine\2022.3.62f3c1`（Unity 中国版），Editor/Data/PlaybackEngines 只有 WebGLSupport 和 windowsstandalonesupport，未装 iOS / Android Build Support 模块，故 `UnityEditor.iOS.Extensions.Xcode.dll` 根本不存在。
- 触发方：AdMob 9.1.0 附带的 EDM 1.2.179，`Assets/ExternalDependencyManager/Editor/1.2.179/Google.IOSResolver.dll`。
- 处理：把该 DLL 的 `.meta` 中 `PluginImporter.validateReferences` 由 1 改 0（等价于 Plugin Inspector 取消勾选 Validate References）。备份在 `.workbuddy/backup/Google.IOSResolver.dll.meta.bak`。
- 为什么不直接禁用 Editor 平台：`GoogleMobileAds.Editor.asmdef` 的 `overrideReferences: false`，会自动引用预编译 DLL，AdMob 编辑器代码会用到 IOSResolver 类型，禁用平台会导致编译报错。
- 若以后真要出 iOS 包，正规做法是装 iOS Build Support（Windows 上无法真正构建 iOS，仍需 macOS）。

## 修复：Unity Ads 报 "Invalid configuration request for gameId:"

- 来源：`com.unity.ads@4.12.0/Runtime/Advertisement/Platform/Editor/EditorPlatform.cs:110`，编辑器模拟平台拿**空 gameId** 去请求配置 URL，HTTP 失败后 catch 里报这句。
- 根因：`Assets/Scripts/Manager/AdsControl.cs` 的 `InitializeUnityAds()` 无条件调用 `Advertisement.Initialize(unityGameId, ...)`；而 `Assets/Scenes/Game.unity` 里 AdsControl 组件的 `androidUnityGameId / iOSUnityGameId / 各 Unity 广告位 ID` 全为空，`ProjectSettings/UnityConnectSettings.asset` 的 UnityAdsSettings 也是 `m_Enabled: 0` 且 GameId 全空。工程实际只走 AdMob（`currentAdsType: 0`，AdMob 用的是 Google 官方测试 ID）。
- 处理：AdsControl 加防护——gameId 为空直接跳过 Unity Ads 初始化；新增 `IsUnityAdsReady(adUnitId)`，`LoadUnityAd / ShowUnityAd / LoadUnityRWAd / ShowUnityRWAd / PlayUnityVideoAd` 全部前置校验；`IsRewardedVideoAvailable()` 补 rewardedAd 空引用判断。
- 若将来要用 Unity Ads：必须在 AdsControl 面板填 gameId + 广告位 ID，并在 Services 里启用 Ads。

## 修复：AdSDK 报 CS0246 找不到 TTSDK

- 报错：`Assets/AdSDK/Scripts/{cebian,PaiHangBang,TikTokPlatform}.cs` 报 `CS0246: The type or namespace name 'TTSDK' / 'TTRewardedVideoAd' / 'TTInterstitialAd' / 'TTSystemInfo' / 'TTUserInfo' could not be found`。
- 根因：工程 `Assets/Plugins/ByteGame/` 里只有 `com.bytedance.bgdt`（ByteGame Develop Tools 3.0.271，只有一个 bgdt.dll），**缺 `com.bytedance.starksdk`（TTSDK 6.9.7）**。`TTSDK` 命名空间来自该包的 `ttsdk.dll`，`TTSDK.UNBridgeLib.LitJson` 来自包内 `LitJson/` 源码。
- 处理：从同级工程 `Unity2022_叠高楼DroppyTower/Assets/Plugins/ByteGame/` 整包复制 `com.bytedance.starksdk`（含 .meta，163 个文件）到本工程同路径。复制前校验过 GUID 无冲突（源 91 个 meta guid 与本工程 1429 个无交集），复制后全工程 1521 个 meta guid 无重复。
- 校验：AdSDK 用到的 `TT.*` 12 个 API（InitSDK/Login/CheckSession/GetUserInfo/NavigateToScene/CreateRewardedVideoAd/CreateInterstitialAd/ShareAppMessage/GetImRankList/SetImRankData/GetLaunchOptionsSync/GetSystemInfo）在 ttsdk.xml 中均存在；asmdef 的 GUID 引用（TTLitJson 986ad24d…）可解析；editor asmdef 里两个 GUID（90bf03ed…、0df35c79…）在源工程同样悬空，属 SDK 自带情况。
- 注意：`TikTokPlatform.cs` 第 7 行 `//#if TickTok` 被注释掉了，所以抖音代码在所有平台都参与编译，必须常驻 TTSDK；若想彻底剥离抖音渠道，应恢复该宏并同步处理 AdManager。
- 顺带：本工程 ProjectSettings 的 WebGL 宏只有 `DOTWEEN`，同级抖音工程是 `WebGL: TTSDK_MIX_ENGINE`（混合引擎相关，不影响 Editor 编译，出抖音 WebGL 包时再考虑加）。
